# AgMemory

Русский · [English](README.en.md) · [Установить с агентом](INSTALL-AGENT.md#русский)

AgMemory — локальная долговременная память для ИИ-агентов. Сохраняйте факты, результаты и процедуры, получайте их через MCP и просматривайте в браузере как в Wiki или на графе связей. Для хранения и поиска не нужны модель и API-ключ. Модель нужна только для чата.

## Быстрый запуск

Проверьте [GitHub Releases](https://github.com/PonomarevRA/ag-memmory/releases): если там есть установщик для вашей ОС и процессора, используйте его. Если установщика нет, запустите из исходников. Нужны Git, .NET 10 SDK согласно [global.json](global.json), Node.js версии 22.12+ или 24 LTS и npm. При первой сборке скачиваются зависимости из NuGet и npm.

```sh
git clone https://github.com/PonomarevRA/ag-memmory.git
cd ag-memmory
dotnet restore ag-memory.slnx
dotnet run --project src/AgMemory.Web/AgMemory.Web.csproj --launch-profile http
```

Откройте [http://localhost:5123](http://localhost:5123). Сервер доступен только локально. Остановка — Ctrl+C. Новая база пуста. **Читать память** открывает Wiki, **Граф памяти** показывает связанные записи, а **Подключить** содержит инструкцию для агента.

На Mac с Apple silicon соберите локальное приложение командой `bash scripts/package-macos-app.sh osx-arm64` и откройте `artifacts/macos/osx-arm64/AgMemory.app`. У такой сборки подпись ad hoc, она предназначена для локального использования. Подробнее о платформах и сборке — в [руководстве по desktop-версии](docs/desktop/distribution.md).

## Подключение ИИ-агента

Откройте раздел **Подключить** или передайте агенту [INSTALL-AGENT.md](INSTALL-AGENT.md#русский). Web и MCP запускаются отдельно. Назначьте каждому клиенту свой идентификатор автора и клиента. Чтобы клиенты видели одни и те же записи, настройте один путь базы и нужную область доступа. [Навык AgMemory](skills/agmemory/SKILL.md) описывает работу с памятью и получение полного пакета навыка.

Скопируйте в Codex, Cursor или Claude:

> Установи AgMemory локально из https://github.com/PonomarevRA/ag-memmory по инструкции INSTALL-AGENT.md. Сохрани существующую память, резервные копии и настройки MCP. Подключи AgMemory отдельным MCP-сервером и проверь реальным вызовом memory_capabilities. Сообщи адрес приложения и результат проверки.

## Данные и обновление

AgMemory хранит данные отдельно от репозитория и приложения. По умолчанию на macOS используется `~/Library/Application Support/AgMemory`; у настроенной установки путь может отличаться. Перед изменениями проверьте фактический каталог в настройках приложения. Перед обновлением сделайте копию по [руководству по резервному копированию](docs/memory/backup-policy.md). Храните API-ключи в локальных настройках или переменных окружения.
