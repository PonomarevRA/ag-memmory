# P1.4. UI табличного просмотра памяти

**Владелец:** Web
**Зависимости:** P1.3
**Статус:** planned

## Цель

Дать понятный безопасный интерфейс для просмотра разрешённой проекции записей.

## Сделать

- Реализовать таблицу, фильтры, сортировку, пагинацию и right-side details через internal ui-kit.
- Явно обозначить read-only режим, область, пустые состояния и недоступность полного текста.
- Обеспечить keyboard navigation, aria-live/busy и закрытие деталей без перезагрузки списка.

## Приёмка

DOM-тесты покрывают фильтр, курсор, детали и отсутствие неразрешённых значений.
