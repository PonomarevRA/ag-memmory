# P1.6. Аудит использования через MCP

**Владелец:** MCP-разработчик
**Зависимости:** P1.5
**Статус:** planned

## Цель

Фиксировать обращения агентов к `memory_recall`, `memory_remember` и `memory_status`.

## Сделать

- Вызывать audit observer после каждой операции, включая error/empty/degraded outcome.
- Получать agent label только из утверждённой конфигурации клиента, не из tool arguments.
- Не ломать stdio transport и результат MCP, если audit storage недоступен.

## Приёмка

Транспортные тесты подтверждают по одному событию на успешный, пустой и неуспешный вызов без изменения ответа.
