# P1.3. Read-only модель записей памяти и API

**Владелец:** Core + Storage
**Зависимости:** P0.2, P0.5, P1.1
**Статус:** completed

## Цель

Создать управляемый табличный просмотр памяти вместо прямого доступа к LanceDB.

## Сделать

- Сделать отдельную server projection с cursor pagination, allowlisted filters и сортировкой.
- Отдавать только утверждённые P0.2 поля; исходный текст — только отдельным opt-in маршрутом.
- Не предоставлять прямой store API, массовый экспорт, embeddings и скрытые идентификаторы.

## Приёмка

Контракт read-only, cursor защищён scope/area, запрещённые поля отсутствуют даже при фильтрах и ошибках.
